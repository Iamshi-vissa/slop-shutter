        How it reads your text
        
        
          
          
        1. Patterns. About sixty rules for stock phrases, model vocabulary, rhetorical templates,
            narrating comments, placeholders and template web styling.
          2. 
          
        2. Context. Technical word senses, code examples, quoted mentions, tests and reference
            formats are checked before a flag counts.
          3. 
          
        3. Rhythm. Sentence and paragraph variation across the whole document.
          4. 
          
        4. Corroboration. A likely-AI verdict needs two independent kinds of evidence.
          5. 
        
        
        
        A score is evidence, not proof. Use it to find passages worth a second look, not
          to accuse anyone.
