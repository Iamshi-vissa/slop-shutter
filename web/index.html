        How the score works
        
      Slop Shutter runs about sixty pattern rules (stock phrases, model vocabulary, rhetorical
          templates, narrating comments, placeholder content, template web styling) and a few
          whole-document measures such as sentence-length variation. Each hit adds evidence, with
          diminishing returns for repeats and a correction for length; a logistic model turns the
          total into a 1–99 score.
      
        
      A score is evidence, not proof. Skilled writers use em dashes, and edited model output can
          read clean. Use it to find passages worth a second look, not to accuse anyone.
